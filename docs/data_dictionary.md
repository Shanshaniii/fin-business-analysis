# 数据字典与来源

输入为 JSON：`synthetic` 布尔值与 `records` 数组。每条记录必须包含唯一 `company_code` + `period`（12 月 31 日）、`name`、`scope`（consolidated / parent）、`currency`（CNY）、`raw_unit`（CNY）、`source_id`、`report_version` 和 `fields`。

| 字段 | 含义 | 类型 |
|---|---|---|
| TotalAssets | 期末资产总额 | 时点存量 |
| TotalLiability | 期末负债总额 | 时点存量 |
| OperatingEvenue | 营业收入，保留历史字段拼写 | 全年流量 |
| NetProfit | 同范围净利润 | 全年流量 |
| ProfitParent | 归属于母公司股东的合并净利润 | 全年流量 |
| OperatingCashFlow | 经营活动现金流量净额 | 全年流量 |

数值使用十进制字符串，缺失使用 null；不要把季度累计值当成年报全年流量。真实数据可由已取得许可的数据库与发行人官方年报交叉核对，保存页码、报告版本、单位和原始来源标识。官方获取入口可使用交易所/发行人投资者关系网站或巨潮资讯，不在仓库分发报告全文。CSMAR 数据须按许可取得，不能用本仓库样例替代。

同比先核定比较基期（含重述前/后）、同主体、同单位和会计口径。真实数据接入并不自动授予可比性。新增适配器应同时核原始文件哈希、字段定义、报告来源和比较基期证据；不要把工程版本号当财报版本。

M01=负债/资产×100；M02=净利润/营业收入×100；M03/M04N/M04P=(当期-可比基期)/可比基期×100；M05=经营净现金流/净利润；M06=经营净现金流/营业收入×100。这些公式不证明经营原因或风险等级。
