# 财务经营分析 V2.0 演示

可运行的 Python 标准库演示：Decimal 计算 7 项指标，保留主体、期间、币种、合并范围及来源；V2 增加 ref-only 引用契约、卡槽隔离及拒绝案例。所有公开样例均为合成数据，页面不调用模型。

## 启动与验证

需要 Python 3.10+，无需第三方依赖。

```sh
python -B -m unittest discover -s tests
python -B -m fin_analysis
python -B -m fin_analysis --serve --port 8765
```

打开 `http://127.0.0.1:8765`。`/api/results` 返回计算与契约案例，`/api/quality` 返回真实历史质量和成本。默认输入为 `data/synthetic.json`；`--input PATH` 可选择自有合法数据。服务仅监听本机。

## V2 改动与边界

- `fin_analysis/answer_v2.py`：答案仅含 facts/references 的 ref ID；财务元数据从调用者可信登记表复制。拒绝额外期间/金额字段、未知引用、重复引用、政策卡进入事实槽，以及财务卡进入参考槽。比较基期保持登记期间。返回的结构有效状态不代表语义验收。
- 页面展示一个合法引用和三个明确拒绝案例，分开展示程序计算、合成契约检查、真实历史结果。
- `numeric_roles.py` 更新为最新内部候选的逐次数值角色实现，保留政策编号/日期与公司金额的隔离。它是受限表达式规则，不代表完整自然语言推理。
- 原有 7 指标与合成样例保留。真实同比仍返回 `accounting_basis_unverified`，直至另行核定同主体、同范围和可比基期。

公开版是独立可移植的合成演示，未发布内部数据、完整推理运行器、模型连接或凭据。内部 r2.3 的 ref-only 提示与 9000 输入/2400 输出配置已做离线检查；输出截断是否改善仍需真实复验。本公开契约只展示引用约束，不包含内部完整工具计划、竞争解释与语义验收链。

## 真实结果与成本

最新已核实历史 Q25 为 9 次请求（1 烟测 + 8 正式），9/9 后端终止，机械 final 2/4：D02 期间/引用卡槽失败，D04 输出截断。该结果不能解释为业务准确率 50%。输入 12,410、输出 4,702、合计 17,112 tokens，传输耗时约 159.063 秒；金额成本未知。

本次公开版离线测试 10/10 通过；内部候选显式离线套件 107/107 通过，两者范围不同，均不是模型业务准确率。历史 r7 的独评必要项 10/16、严格 1/4 等原始结果保留在 `docs/quality_and_cost.json`，未用新演示覆盖。
