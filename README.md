# 财务经营分析 V2.0 演示

可运行的 Python 标准库演示：Decimal 计算 7 项指标，保留主体、期间、币种、合并范围及来源；V2 增加 ref-only 引用契约、卡槽隔离及拒绝案例。所有公开样例均为合成数据，页面不调用模型。

## 启动与验证

需要 Python 3.10+，无需第三方依赖。

```sh
python -B -m unittest discover -s tests
python -B -m fin_analysis
python -B -m fin_analysis --serve --port 8765
```

打开 `http://127.0.0.1:8765`。`/api/results` 返回计算与契约案例，`/api/quality` 返回真实历史质量和成本。默认输入为 `data/synthetic.json`；`--input PATH` 可选择自有合法数据。服务仅监听本机。

## V2 改动与边界

- `fin_analysis/answer_v2.py`：答案仅含 facts/references 的 ref ID；财务元数据从调用者可信登记表复制。拒绝额外期间/金额字段、未知引用、重复引用、政策卡进入事实槽，以及财务卡进入参考槽。比较基期保持登记期间。可选 `required_tool_refs` 由调用程序的可信工具轨迹提供：漏引必需财务产出则拒绝，不自动补答案；未知或非财务要求也拒绝。省略此参数保持原接口行为。结构有效不代表语义验收。
- 页面展示合法引用、字段/卡槽/虚构引用拒绝，以及工具产出已引用和漏引两个合成案例，分开展示程序计算、合成契约检查、真实历史结果。
- `numeric_roles.py` 更新为最新内部候选的逐次数值角色实现，保留政策编号/日期与公司金额的隔离。它是受限表达式规则，不代表完整自然语言推理。
- 原有 7 指标与合成样例保留。真实同比仍返回 `accounting_basis_unverified`，直至另行核定同主体、同范围和可比基期。

公开版是独立可移植的合成演示，未发布内部数据、完整推理运行器、模型连接或凭据。内部 r2.3/r2.4 已在同两道开发题完成真实复验；本公开契约只展示引用与工具产出覆盖约束，不包含完整工具计划、竞争解释或语义验收链。`required_tool_refs` 不能从模型答案生成，也不能把模型提交的登记表当作可信来源。

## 真实结果与成本

历史 Q25 为 9 次请求（1 烟测 + 8 正式），9/9 后端终止，机械 final 2/4：D02 期间/引用卡槽失败，D04 输出截断。输入 12,410、输出 4,702、合计 17,112 tokens，传输耗时约 159.063 秒；原失败不覆盖。

新服务两轮各 5 次生成（烟测1+正式4）全部后端终止；另 1 次元数据 POST 不生成。r2.3 两题机械 final 0/2；修复后 r2.4 机械 final 2/2。独评将交付系统和模型原文分开：

|r2.4 评分范围|必要项|严格整题|
|---|---:|---:|
|交付系统 final（含明确标注的程序事实与口径表）|7/8|1/2|
|模型 raw 原文|5/8|0/2|

程序补齐事实与口径属于系统交付能力，不计为模型自主解释。D04 第一候选的机制方向和判别条件仍不足；两道已知开发题不代表泛化准确率。两轮合计输入 12,790、输出 2,516，共 15,306 tokens，客户端 174.174 秒；金额未知。模型 digest 相同，但新旧服务版本和冷启动状态不同，不能把耗时变化归因于提示优化。

公开版离线测试 13/13；内部最新显式离线套件 116/116，范围不同，均不是模型准确率。历史 r7 必要项 10/16、严格 1/4 等原始结果保留在 `docs/quality_and_cost.json`。分轮成本、双列评分与限制以该文件为准。
